# Cuework 字幕校整工作台

[開啟線上工作區](https://miiduoa.github.io/cuework/) · [English](../README.md)

編輯 SRT／WebVTT 的文字與時間，檢查重疊、閱讀速度與過長字幕，再匯出檔案。

1. 匯入字幕，或用內建範例熟悉時間軸與右側編輯面板。
2. 選取字幕調整文字、開始與結束時間；Shift timing 可將整份字幕前移或後移。
3. Save version 保存版本；Export 匯出 SRT 或 VTT。儲存為手動操作，匯出不等於保存版本。

本機影片只用於預覽，不會上傳或寫入版本。範例附有明確標示的插畫畫面，沒有假裝內建影片。

## 線上版與本機版

線上版使用目前瀏覽器的 IndexedDB。不同瀏覽器、裝置和網站來源不共用資料，清除網站資料會刪除版本；重要字幕請另行匯出。

本機全端版使用 Node.js 與 SQLite，需要 Node.js 24 以上：

```sh
npm ci
npm run build
npm start
```

開啟 `http://127.0.0.1:4173`。資料保存在 `.data/cuework.sqlite`。服務只監聽本機，沒有帳號或雲端同步功能。

兩種模式都保留版本紀錄。還原會新增版本；兩個視窗同時修改時，晚到的舊版本會收到衝突提示，未儲存文字仍可匯出。

## 格式限制

單次最多 1 MiB、1,000 段字幕，每段 4,000 字元。支援毫秒時間；負時間或無效起迄時間不能匯出。閱讀速度與行數只提供提示，刻意重疊仍可保留。

VTT 的識別碼與位置設定只會保留在 VTT 匯出。NOTE、STYLE、REGION、標頭中繼資料與內嵌時間標記目前會明確拒絕。文字中的 markup 原樣保留，預覽不執行 HTML。
